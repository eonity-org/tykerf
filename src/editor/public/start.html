        Styles and scripts for every page

        This code goes in the head of every page, before the page's own: a stylesheet, a <style> or a <script>, meta tags. Colours and fonts are the theme, in the Page tab of any page. Scripts here run on every page.

        Publish the site

        TYKERF exports the site and commits it to a GitHub repository. Connect that repository once to GitHub Pages, Cloudflare Pages or Netlify, and every publish goes live. Only the files TYKERF published there are ever replaced or removed.
